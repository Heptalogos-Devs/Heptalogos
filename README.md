# Heptalogos

Heptalogos 是基于 [Mai-with-u/MaiBot](https://github.com/Mai-with-u/MaiBot) 发展持续人工主体的 Next Gen MaiBot Kernel。本仓库 `main` 从上游 `main` 提交 [`2a9af62cec37035d29237acbe2cf3adceb700b27`](https://github.com/Mai-with-u/MaiBot/commit/2a9af62cec37035d29237acbe2cf3adceb700b27) 出发，保留 MaiBot 完整 Git 历史、源码和 [GPL-3.0 许可](LICENSE)。

当前是尚未改造主体内核的 Fork 基线。MaiBot 的通信、多模态消息、插件接口与市场、模型和 Prompt 资源、学习能力及 WebUI/Dashboard 是后续产品基础。Heptalogos 将逐步发展主体 Reactor、世界、生活、统一注意与行动；[Nous](https://github.com/Heptalogos-Devs/Nous-Wave) 是独立长期认知服务和主体认知权威。

产品责任与未完成方向见 [Heptalogos 架构](docs/HEPTALOGOS.md)，最高产品需求见 [Architecture-Vault 项目宪纲](https://github.com/Heptalogos-Devs/Architecture-Vault/blob/main/项目宪纲.md)。MaiBot 的[中文说明](docs/README_CN.md)、[英文说明](docs/README_EN.md)、[部署文档](https://docs.mai-mai.org/manual/)和[插件开发文档](https://github.com/Mai-with-u/maibot-plugin-sdk/blob/main/docs/guide.md)继续适用于当前上游基线。使用前请阅读 [EULA](EULA.md) 与[隐私协议](PRIVACY.md)。
