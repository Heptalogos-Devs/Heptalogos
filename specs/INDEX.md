# Normative Spec index

This index routes the current implementation contracts for every Heptalogos
semantic boundary. Read the owner Spec before changing its contract; use
Architecture for concepts, Governance for standing rules, Dependencies for
mechanics routes, Roadmap for sequencing, Plans for authorization, and
Qualification for observed evidence. Prefixes are secondary search aids for
requirement IDs.
